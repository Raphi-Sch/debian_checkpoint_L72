# Gaia boot menu with hidden options

### Normal options :
- 1 : Start in normal Mode
- 2 : Start in debug Mode
- 3 : Start in maintenance Mode
- 4 : Restore to Factory Defaults (local)
- 5 : Install/Update Image from Network
- 6 : Restart Boot-Loader
- 7 : Run Hardware diagnostics (not implemented on CheckPoint 770 / L72)
- 8 : Upload preset configuration file
- 9 : Delete preset configuration file

### Hidden options :
- 0 : Current system informations
- a : Vendor menu
- b : Boot any uImage from TFTP server
